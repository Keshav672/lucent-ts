# WRITE AN AD

One ad per session. A new ad means a new chat.

STEP 0 — Read the desk silently: ads/ad-desk.md, ads/what-works.md, ads/roster.md. Use them to
propose answers later.

STEP 1 — Ask three things together, then stop. Write nothing.
1. Format: video, image video, native, or static?
2. Concept, in my words (one vague line is fine)
3. Mode: ideation, imitation, or iteration?
If I already gave any, confirm and move on. "Iteration on Batch #x" → that number is the lookup key.

STEP 2 — Route: copywriting/method/mode-ideation.md · mode-imitation.md · mode-iteration.md.
Layer copywriting/method/format-criteria.md for the format.

STEP 3 — Gather. Run the mode's questions in batches grouped by section. Propose, don't interrogate:
where the files already answer, give the answer and ask me to confirm. Ask more rather than fewer.

STEP 4 — Research linking: copywriting/method/research-linking.md. No writing. No length limit.
Present conflicts; never recommend killing the concept. Re-run if the concept is redirected.

STEP 5 — Copywriting by section: copywriting/method/copywriting-by-section.md. Foundation once, then
the HOOK, BRIDGE and CTA layers as each section is written. Pull from copywriting/references/.

APPROVAL GATES:
1. Brief approved, before the research sweep
2. Brainstorm approved, before the copywriting layer opens
3. Angle + hook approved, before the full script (cheap to change now, expensive later)
4. Bridge locks at variation 1; variations 2 and 3 are hook swaps over it
5. End of batch: only after all 3 close, produce on-screen text, headline and primary text

STEP 6 — Deliver. Rough script only, one variation at a time. No visuals, on-screen text, headline or
primary text unless I ask. Wait for me to close each variation ("variation 1 done, final: …"). Before
variations 2 and 3, run the mini-brainstorm in copywriting/method/variation-design.md. Save drafts to
ads/drafts/.

FINAL PASS — before I see anything: copywriting/method/final-polish-pass.md, all ten steps.

If you need a fact you don't have, ask in the question phase. Never annotate a draft with uncertainty.
