# Variation design

A batch is 3 variations: **3 hooks · 1 shared bridge · 1 or 3 CTAs.**
Variations 2 and 3 must be VERY different from 1 in how they hook the audience. Not a reworded hook.

| | Changes | Held constant |
|---|---|---|
| V1 | — | establishes the bridge |
| V2 | hook FORMAT + VOC entry point | the bridge |
| V3 | hook FORMAT + VOC entry point, different again | the bridge |

The bridge locks at V1 so a performance difference is readable as the hook. If the bridge drifts, the batch teaches nothing. If V2 could be described as "V1 worded differently", rebuild it.

Before V2 and before V3, run a **MINI-BRAINSTORM** back into the research: a different VOC entry point (a different quote, emotional door, or sub-avatar moment), a different hook format, and a different mechanic where possible (loop → promise). Present it before writing.

## Hook format menu
Pick a different one per variation: big headline text over the visual · comment screenshot as the opener · reply-to-comment · in-media-res (cut the hook, start at the bridge) · split-screen / side-by-side · security-cam or documentary framing · talking head straight to camera · voiceover over a demo · the problem personified, speaking · two-person dialogue · question on screen · stat or number first · visual-only cold open.
